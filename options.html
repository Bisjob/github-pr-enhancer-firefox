⚙️ GitHub PR Enhancer Settings

Configure GitHub personal access tokens. A default token is used for all owners unless you specify an owner-specific override below.

Default token

Used for every owner / organization that does not have a specific token set below. Must be a fine-grained PAT starting with github_pat_.  Create a token ↗

Per-owner tokens

Set a different token for a specific GitHub user or organization name (e.g. my-org). Owner-specific tokens take priority over the default token.

📝 How to create a fine-grained token
  1. Click "Create a token ↗" link above (or go to GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens).
  2. Give the token a name (e.g. GitHub PR Enhancer).
  3. Under Resource owner, select the user or organization this token will cover.
  4. Under Expiration, select a date up to one year from now.
  5. Under Repository access, choose the relevant repositories (or "All repositories").
  6. Under Permissions → Repository, enable Pull requests — Read-only and Deployments — Read-only.
  7. Click Generate token and copy the value (starts with github_pat_).
  8. Paste it in the field above and click Save all settings.
